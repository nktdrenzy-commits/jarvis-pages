01 · 系统架构

架构总览

Jarvis 基于 OpenClaw Agent 构建，核心数据存储在本地 Obsidian Vault，通过飞书生态实现主动交互。

用户

通过飞书与 Jarvis 交互

Jarvis (OpenClaw Agent)

AI 推理 · 任务编排 · 记忆管理

Obsidian Vault

知识库 + 配置中心

飞书生态

IM · 日历 · 任务 · 云文档

MiniMax / Qwen / Tavily

模型能力 · Embedding · 联网搜索

数据流向：用户请求 → OpenClaw Agent → 读取 Vault 中的记忆/配置 → 调用模型能力 → 执行任务（飞书消息/日历/文件操作）→ 结果写回 Vault

06 · 安全机制

安全与加密

🔐 凭证加密

所有 API Key 使用 OpenSSL AES-256-CBC + PBKDF2 加密存储。密钥文件权限 600，仅自己可读写。

🛡️ 权限控制

Secrets 目录严格权限控制，对话中绝不出现明文凭证内容。任何外部操作前必须确认。

📍 本地优先

所有数据存在你自己的 Obsidian Vault，不经过第三方服务器。飞书 OAuth 仅用于消息推送和日历管理。

🔄 定时备份

OpenClaw Cron 自动化备份到飞书知识库。每天 03:00 同步核心配置，每天 23:00 检查每日笔记。

📋 审计追溯

所有敏感操作记录在案。配置变更、文件访问都有时间戳，可追溯、可回滚。

🚫 防误删

删除操作前必须二次确认。使用 trash 替代 rm，避免误删重要文件。
